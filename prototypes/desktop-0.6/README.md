# Desktop prototype 0.6 (reference only)

A single-file Basecamp view (≈3,000 lines) that tried out the Track A features of the Freequencies plan in the
Freequencies look. It is **not** built or shipped: it was broken into the issues in `docs/issues/` and rebuilt
on top of Scala's own calendar app (`freequencies-ui/`). Screenshots: `freequencies-0.6-*.png`.
