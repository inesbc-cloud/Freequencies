# Fonts

- `BebasNeue-Regular.ttf` — Bebas Neue by Dharma Type, SIL Open Font License (`OFL-BebasNeue.txt`). Display type.
- `FT88-Serif.otf` — **add this file.** FT88 Serif by Velvetyne Type Foundry (libre, SIL OFL), from
  https://velvetyne.fr/fonts/ft88/ . Body and label type. Until it is here, the view falls back to the
  system monospace, so nothing breaks.

Both are loaded with `FontLoader` from `FreequenciesView.qml`, relative to the `qml/` folder.
